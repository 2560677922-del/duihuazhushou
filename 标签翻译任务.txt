========================================================================
可选参数（默认值一般够用）
========================================================================
  --base-url https://api.xuancat.cn     换一个中转/接口
  --model gemini-3-pro-preview          换一个模型
  --batch 200                           每次请求送多少条
  --concurrency 4                       同时几个请求
  --only 服装                           只翻某一类（服装/外表/动作/
                                        场景/动物/风格/NSFW）
  --dry-run                             不调接口，只看会翻什么

例：只翻 NSFW
    node scripts/translate-tags.mjs --only NSFW

========================================================================
产出说明
========================================================================
最终文件：scripts\tag-translations.json

格式：
  "tags": {
    "black_jacket": { "zh": "黑夹克", "group": "服装", "sub": "outfit" },
    ...
  }

tag = 标准英文写法 → **发给生图模型用这个**
zh  = 中文           → **只给界面显示用**

所以界面上会显示「黑夹克」，但真正发给模型的仍然是 black_jacket。
